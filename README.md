# PL: Przewidywanie osłabień czempionów w grze League of Legends
Projekt na kurs Wstęp do Analizy Danych. Celem projektu było utworzenie modelu który z dokładnością 50% przewidywałby czy czempion zostanie czy nie osłabiony. Związane z tym koszta zostały opisane w pliku.

Plik .pptx zawiera prezentacje na temat tego repozytoria, a .R to kod związany z obróbką danych, oraz samym modelem.

# EN: Predicting-nerfs-for-champions-in-League-of-Legends 
Project for the "Introduction to Data Analysis" course. The project aimed to develop a model predicting champion nerfs with accuracy of 50%, regardless of the trade-offs. Any significant negative consequences are detailed in the project.

The .pptx file contains a detailed description of the project's methodology and reasoning, while the .R file includes all the necessary code.
